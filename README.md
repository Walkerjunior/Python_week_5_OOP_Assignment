# Python_week_5_OOP_Assignment

This repository contains final solutions for the Object-Oriented Programming (OOP) assignment.

## 🏗️ Assignment 1: Design Your Own Class
- `superhero.py`: Defines a `Superhero` class and a subclass `FlyingHero` demonstrating inheritance and encapsulation.

## 🎭 Activity 2: Polymorphism Challenge
- `vehicles.py`: Defines a base `Vehicle` class with subclasses `Car`, `Plane`, and `Boat` showing polymorphism using the `move()` method.

## ▶️ How to Run
1. Make sure you have Python installed.
2. Run the `main.py` file:
   ```bash
   python main.py
   ```
